# پچ مدرسه‌یار دانش‌آموز — V1.10.0

## این پچ چه چیزی را اصلاح می‌کند؟
- منوی پایین «نمرات» به صفحه نمرات متصل می‌شود، نه گفت‌وگو با معلم.
- پنجره ارسال آزمون با درصد و نوار پیشرفت واقعیِ بارگذاری درخواست نمایش داده می‌شود.
- ارسال فوری فقط پاسخ آزمون جاری را می‌فرستد؛ واکشی داشبورد و نتایج بعد از رسید و در پس‌زمینه انجام می‌شود.
- پاسخ‌ها پیش از اتصال در صف محلی ذخیره می‌شوند و در صورت خطای شبکه از بین نمی‌روند.

## اعمال روی هاست
1. از فایل فعلی `app/student/app.js` پشتیبان بگیر.
2. فایل `server-integration/INSTALL-ROOT/student/app.js` را به مسیر `app/student/app.js` هاست کپی و جایگزین کن.
3. به `server.mjs` یا دیتابیس دست نزن.

## ساخت نسخه اندروید
1. کل سورس را به مخزن GitHub پروژه منتقل کن و تغییرات را Commit کن.
2. از بخش Actions، گردش‌کار `Build Android APK` را اجرا کن.
3. خروجی `Madreseyar-Student-Debug-APK` را دریافت کن.
4. نسخه جدید `1.10.0` با `versionCode 10` است. امضای APK باید با نسخه قبلی سازگار باشد تا نصب روی همان برنامه ممکن شود.

## بررسی
- `node --check server-integration/INSTALL-ROOT/student/app.js`
- `node --test tests/*.test.mjs`
- مجموعه تست در محیط اجرا: ۴۷ موفق، ۰ ناموفق.

در محیط فعلی Android SDK و Gradle نصب نبود؛ بنابراین APK در همین محیط کامپایل نشده و باید با GitHub Actions یا محیط Android SDK ساخته شود.
