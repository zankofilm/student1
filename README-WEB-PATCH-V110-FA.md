# پچ پنل وب دانش‌آموز — V1.10.0

1. ابتدا از فایل فعلی هاست `app/student/app.js` نسخه پشتیبان بگیر.
2. فایل `app/student/app.js` داخل همین ZIP را در همان مسیر روی هاست جایگزین کن.
3. به `server.mjs`، دیتابیس و سایر فایل‌های هاست دست نزن.
4. برای اصلاح آیکن «نمرات» نیز باید APK جدید V1.10.0 از سورس کامل ساخته و نصب شود؛ این پچ فقط کد پنل و ارسال آزمون را به‌روز می‌کند.

این پچ پنجره پیشرفت ارسال آزمون و ارسال سریع‌تر آزمون جاری را فعال می‌کند. اگر شبکه یا سرور خطا بدهد، پاسخ‌ها در صف محلی می‌مانند و برنامه ادعا نمی‌کند که سرور تحویل را تأیید کرده است.
