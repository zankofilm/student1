# پچ پنل وب مدرسه‌یار دانش‌آموز — نسخه ۱.۱۱.۰

1. از فایل `app/student/app.js` روی هاست پشتیبان بگیر.
2. فایل `app.js` داخل ZIP را در مسیر `app/student/app.js` جایگزین کن.
3. این پچ مقایسه تغییرات، گزارش به‌روزرسانی، اعلان‌های محلی و نمایش آن‌ها در مرکز اعلان‌ها را اضافه می‌کند.
4. برای اعلان سیستمی اندروید، APK نسخه ۱.۱۱.۰ نیز باید نصب شود؛ پچ وب به‌تنهایی اعلان سیستمی اندروید را فعال نمی‌کند.
5. نیازی به تغییر `server.mjs` یا دیتابیس نیست.
6. این قابلیت هنگام همگام‌سازی دستی کار می‌کند. اعلان از راه دور هنگام بسته بودن برنامه، قابلیت جداگانه‌ای است.
