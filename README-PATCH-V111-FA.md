# پچ مدرسه‌یار دانش‌آموز — نسخه ۱.۱۱.۰

## قابلیت جدید
پس از به‌روزرسانی دستی، برنامه تغییرات واقعی را با داده قبلی مقایسه می‌کند و گزارش می‌دهد چه آزمون‌هایی تازه فعال شده‌اند، چه تکلیف یا اطلاعیه‌ای اضافه شده و آیا نمره یا کارنامه‌ای تغییر کرده است. گزارش در مرکز اعلان‌ها می‌ماند و در اندروید، هنگام وجود تغییر واقعی، اعلان سیستمی هم نمایش داده می‌شود. مبنای مقایسه مستقل از تازه‌سازی پس‌زمینه است تا تغییرات جدید از دست نروند.

## نصب
1. ابتدا از فایل فعلی هاست `app/student/app.js` نسخه پشتیبان بگیر.
2. پچ وب `Madreseyar-Student-Web-Patch-V1.11.0.zip` را استخراج کن و فایل `app.js` آن را در مسیر `app/student/app.js` روی هاست جایگزین کن.
3. برای اعلان سیستمی اندروید، سورس کامل نسخه ۱.۱۱.۰ را در GitHub قرار بده و از Actions خروجی APK بگیر.
4. APK باید با همان کلید امضای نسخه قبلی ساخته شود. پیش از نصب، پاسخ‌های ذخیره‌شده آزمون‌ها را محافظت کن.
5. نیازی به تغییر `server.mjs` یا دیتابیس نیست.

## رفتار اعلان
- فقط پس از همگام‌سازی دستی نمایش داده می‌شود.
- وقتی آزمون تازه فعال شود، در گزارش نام آزمون نمایش داده می‌شود.
- وقتی تغییر جدیدی وجود نداشته باشد، گزارش «همه‌چیز به‌روز است» نشان داده می‌شود و اعلان سیستمی تکراری صادر نمی‌شود.
- اعلان محلی به Firebase نیاز ندارد؛ اعلان از راه دور هنگام بسته بودن برنامه نیازمند تنظیمات مستقل Firebase است.

## بررسی
- `node --check server-integration/INSTALL-ROOT/student/app.js`
- `node --check server-integration/INSTALL-ROOT/server.mjs`
- `node --test tests/*.test.mjs`
- APK در این محیط کامپایل نشده و اعلان روی گوشی واقعی هنوز تأیید نشده است.
