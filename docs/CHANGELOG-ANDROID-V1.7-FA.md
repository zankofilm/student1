# Android V1.7 — دوربین پاسخنامه تشریحی

- پشتیبانی از گرفتن عکس مستقیم با دوربین گوشی در فرم وب آزمون از طریق `WebChromeClient.onShowFileChooser` و `FileProvider`.
- گالری و انتخاب چند فایل مانند قبل کار می‌کند.
- آیکون، داشبورد دخترانه، اثر انگشت، رفع دکمه شروع آزمون V1.5 و ارسال نهایی V1.6 دست‌نخورده‌اند.
- نیاز به نصب **پچ وب P67.19.8 روی هاست** برای نمایش دکمه‌های جداگانه دوربین/گالری دارد.
- فایل `server-integration/` از نسخه‌های قبلی صرفاً نمونه است و نباید روی هاست نصب شود؛ برای P67.19.8 فایل `server.mjs` نیاز به جایگزینی ندارد.
- در GitHub پس از آپلود و Commit فایل‌های تغییر یافته، Actions → Build Android APK را اجرا کنید.
- آزمون ساختاری ۲۷/۲۷ موفق؛ کامپایل Gradle و دوربین واقعی روی گوشی هنوز آزمایش نشده‌اند.
